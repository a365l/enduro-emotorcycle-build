# Build Logbook

Same structure as my quadcopter project log.

- `session/` - one file per workshop session: `#NN Title YY-MM-DD.md`
- `session/media/YY-MM-DD/` - photos, videos and spectrograms from that session, numbered in the order they're referenced
- `week/` - weekly summaries

Each session covers: What I did, Decisions made, Related files, Blockers / open questions, Next session, and a photo log explaining every photo.
